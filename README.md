# raviteja-gadde.github.io

Personal site, served by GitHub Pages from `main`. Plain HTML and CSS, no build step.

- `index.html` — the one page: what I do, how I work, what's in public, where else to find me.
- `posts/` — writing, one dated HTML file per post (`YYYY-MM-DD-slug.html`), listed on the index once the first one exists.

Edit, commit, push. Pages rebuilds in about a minute.
